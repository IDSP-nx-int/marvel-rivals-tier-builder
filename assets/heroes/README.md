# Retratos opcionales

El proyecto **no incluye arte protegido de terceros**. Los retratos aprobados por el usuario se pueden añadir aquí como archivos `webp` nombrados por slug, por ejemplo `elsa-bloodstone.webp`.

Tras añadir cada archivo, incluye su ID estable en `manifest.json`, por ejemplo `"hero.elsa-bloodstone"`. Solo los héroes presentes en el manifest intentan cargar una imagen. Los demás muestran iniciales locales.

Antes de publicar, verifica licencias, términos de uso y atribuciones correspondientes. No pongas enlaces a imágenes de sitios externos dependientes de hotlink.
